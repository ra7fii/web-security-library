# Contributing

Thanks for helping improve the library. Pull requests and issues are welcome.

## The one hard rule

**Only add a file if its license explicitly allows redistribution** (for example Creative Commons, MIT or Apache 2.0) and you downloaded it from the official source. Pull requests that add commercial books, leaked course material or "free PDF" copies of paid content will be closed.

If a resource is free to read but its terms do not allow re-hosting, add a link instead.

## Adding a hosted document

1. Put it in the matching folder under `docs/`, creating one if needed.
2. Name it `<Publisher>-<Title>-<Version>.pdf`, with no spaces.
3. Add a row to the *Library* table in `README.md` with the version and a one-line description.
4. Add its source URL and license to *License and attribution* in `README.md`.

## Adding a link or book

- Free resources go in the *Free resources* table in `README.md`.
- Commercial books go in `reading-list.md` with author, publisher, year, level, a short summary and a link to the publisher or author.
- Labs go in `learning-path.md` next to the topic they teach.

Check that every link works before you open the pull request.
